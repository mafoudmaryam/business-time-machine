# Fonts (self-hosted)

These files are served from the app itself, so the app looks the same when Google Fonts is blocked
or the computer is offline. All three are free under the SIL Open Font License 1.1.

| Font | Used for | Source |
| --- | --- | --- |
| Nunito (variable, weights 200-1000) | headings | https://github.com/googlefonts/nunito |
| Inter (variable) | body text | https://github.com/rsms/inter |
| Patrick Hand | the one handwritten slogan and small accents | https://github.com/google/fonts/tree/main/ofl/patrickhand |

Files come from the `@fontsource` packages (latin and latin-ext only).
